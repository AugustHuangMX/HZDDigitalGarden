# ADHD Coach System

这个文件夹是一套给 Obsidian 日记用的 ADHD 友好执行系统。它不是医疗、诊断或心理治疗记录；它的目标更朴素：每天帮你把注意力、任务、学习和生活从脑内搬到纸面上。

## 使用方式

每天只需要三个动作：

1. 早上或开始学习前，用 `daily-template.md` 做 3-5 分钟开机。
2. 卡住、拖延、切换任务困难时，打开 `protocols.md` 选一个流程。
3. 睡前或结束工作前，用当天日记最后的复盘区做 3 分钟收尾。

每周一次，用 `weekly-review-template.md` 做 15-20 分钟复盘。复盘只看证据，不审判人格。

## 文件说明

- `daily-template.md`: 每日开机、任务拆解、学习记录、睡前复盘模板。
- `weekly-review-template.md`: 每周复盘模板，用来发现模式和设计下周实验。
- `protocols.md`: 拖延、卡住、过载、切换困难时的短流程。
- `prompts.md`: 可以直接发给 Codex 的 ADHD coach-like 提示词。

## 运行原则

1. 先降低阻力，再追求效率。
2. 每天只设一个真正的锚点任务。
3. 计划是临时脚手架，不是道德考试。
4. 记录事实优先于解释原因。
5. 复盘只问：什么有用，什么太重，下一次怎么更轻。
