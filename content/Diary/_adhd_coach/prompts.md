# Codex Prompts

## Morning check-in

```text
Codex，请进入 ADHD coach-like 模式，帮我做早间开机。
请先问我最多 3 个问题，然后帮我确定：
1. 今日一个锚点任务
2. 这个任务的最低成功标准
3. 第一个 10 分钟动作
4. 一个现实的时间块安排
语气请直接、温和、不要鸡血。
```

## Task breakdown

```text
我现在要做这个任务：[任务]
请帮我拆成 ADHD 友好的步骤：
1. 每一步都要肉眼可见
2. 第一步必须小于 10 分钟
3. 标出哪些步骤可以跳过或延后
4. 给我一个“做到哪里就算今天成功”的标准
```

## When stuck

```text
我卡住了：[描述]
请不要先给大道理。请帮我：
1. 猜测可能的执行功能阻力
2. 把任务缩小 70%
3. 给我一个 2 分钟启动动作
4. 陪我做一次简短复盘
```

## End-of-day review

```text
请基于我今天的日记做 ADHD 友好的收尾复盘：
1. 先找完成的证据
2. 再找卡住的模式
3. 不批评人格
4. 给明天一个更轻的实验
5. 最后输出明天醒来后的第一步
```

## Weekly review

```text
请基于我这一周的日记做 ADHD 友好的周复盘：
1. 总结本周有效的条件
2. 总结本周最常见的卡点
3. 识别学习和生活中的 1-2 个模式
4. 为下周设计最多两个实验
5. 帮我选一个下周锚点
```

## Shame reset

```text
我现在因为拖延/没完成任务很羞耻。
请用现实、温和、不鸡汤的方式帮我重置：
1. 区分事实和自我攻击
2. 找一个没有归零的证据
3. 给我一个 10 分钟补救动作
4. 帮我写一句今天可以接受的收尾语
```
