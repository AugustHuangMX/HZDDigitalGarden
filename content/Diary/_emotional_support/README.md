# Emotional Support

这个文件夹不是模板库，而是 Codex 和用户长期对话的轻量记录区。

用户保持原本自然写日记的方式。Codex 每天通过阅读日记和聊天，帮助用户更了解自己、梳理感受、看见关系和压力模式，并给出温和建议。

## 文件

- `memory.md`: 长期记忆。记录稳定偏好、重要背景、支持方式和需要记住的事实。
- `progress.md`: 对话进展。记录重要对话后的主题、洞见和下次可继续的线索。
- `working-understanding.md`: 非临床工作理解。记录 Codex 对用户的观察和假设，不是医学诊断。

## 原则

- 不要求用户填写模板。
- 不把用户固定成标签。
- 观察可以被修正，建议要轻。
- 先理解，再建议。
- 记录少而有用，避免把隐私原文搬进这里。
- 长期记录不需要每次对话结束都更新；只在出现值得保留的信息、偏好、洞见或阶段性变化时更新。
